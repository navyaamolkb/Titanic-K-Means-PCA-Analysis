This project performs unsupervised machine learning on the Titanic dataset using K-Means clustering and PCA.
# Steps
Load and preprocess data
 - Remove missing values
 - Encode categorical columns
 - Scale features
K-Means Clustering
 - Groups passengers into 3 clusters based on similarities.
PCA (Principal Component Analysis)
 - Reduces data to 2 components for visualization.
Visualization
 - Scatter plot showing clusters in PCA space.
